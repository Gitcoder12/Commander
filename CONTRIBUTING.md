# Contributing to Commander

1. Read README.md, ACTIVITY_LOG.md and FEATURE_UPGRADE_PLAN.md.
2. Check issue #4 security work before making API changes.
3. Work on a feature branch and define acceptance criteria.
4. Add tests for invalid input, disallowed origins, rate limits, timeouts and model failures.
5. Keep provider calls mocked in tests; never use real credentials in CI.
6. Report token/cost and quality measurements with a clear method.
7. Open a PR with exact tests and limitations.

Human maintainers approve production configuration, credentials, merges and deployments.
